## 2. المعلومات التي تُجمع

لا يستخدم الموقع أدوات تحليل زيارات مملوكة له، أو أدوات تتبع إعلانية، أو نشرة
بريدية، أو نظام دفع، أو نموذج تواصل يعمل على خادم الموقع.

ومع ذلك، قد تُعالَج معلومات في الحالات الآتية:

- **سجلات الاستضافة والأمان:** يُستضاف الموقع عبر GitHub Pages، وتحتفظ GitHub
  بعناوين IP للزوار لأغراض الأمان. راجع
  [بيان خصوصية GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
- **تفضيل السمة:** يحفظ الموقع اختيارك للسمة الفاتحة أو الداكنة في التخزين
  المحلي لمتصفحك. يبقى هذا التفضيل على جهازك ولا يرسله الموقع إليّ.
- **الرسائل التي تختار إرسالها:** إذا تواصلت معي عبر البريد الإلكتروني أو
  واتساب، أتلقى المعلومات التي تختار تضمينها، مثل الاسم وبيانات التواصل
  ومحتوى الرسالة.
- **التعليقات:** تُوفَّر التعليقات عبر Giscus وGitHub Discussions. عند نشر
  تعليق، قد تعالج GitHub وGiscus معلومات حساب GitHub الخاص بك ومحتوى التعليق
  والبيانات الوصفية المرتبطة به. قد تكون التعليقات مرئية للعامة.

## 3. كيف تُستخدم المعلومات

تُستخدم المعلومات فقط من أجل:

- تشغيل الموقع وتأمينه وتحسينه؛
- تذكّر تفضيل السمة؛
- الرد على الرسائل واستفسارات المشاريع والفرص المهنية؛
- إدارة التعليقات والإشراف عليها؛ و
- الامتثال للالتزامات القانونية أو الحماية من إساءة الاستخدام.

## 4. ملفات تعريف الارتباط والتقنيات المشابهة

لا يضع Momentadev ملفات تعريف ارتباط مملوكة للموقع لأغراض التحليلات أو
الإعلانات. التخزين الوحيد الذي يتحكم فيه الموقع هو التخزين المحلي لتفضيل
السمة.

يمكنك إزالة هذا التفضيل في أي وقت بمسح بيانات الموقع من متصفحك. قد تستخدم
GitHub أو Giscus أو واتساب أو Microsoft أو أي خدمة أخرى تختار فتحها ملفات
تعريف ارتباط أو تقنيات مشابهة وفق سياساتها الخاصة.

## 5. الخدمات الخارجية

يستخدم الموقع الخدمات التالية أو يربط بها:

- **GitHub Pages** لاستضافة الموقع وتوفير سجلات أمان على مستوى البنية التحتية.
  راجع [بيان خصوصية GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
- **Giscus وGitHub Discussions** لتوفير ميزة التعليقات. تخضع التعليقات لممارسات
  الخصوصية لدى [Giscus](https://giscus.app/) وGitHub.
- **واتساب**، الذي لا يُفتح إلا عند اختيار رابط التواصل عبر واتساب. راجع
  [سياسة خصوصية واتساب](https://www.whatsapp.com/legal/privacy-policy).
- **Outlook/Microsoft** لمعالجة الرسائل التي تختار إرسالها إلى البريد المنشور.
  راجع [بيان خصوصية Microsoft](https://www.microsoft.com/en-us/privacy/privacystatement).

لا أتحكم في ممارسات معالجة البيانات لدى هذه الخدمات. يُرجى مراجعة سياساتها قبل
استخدامها.

## 6. الأساس القانوني (لزوار المنطقة الاقتصادية الأوروبية/المملكة المتحدة)

عند انطباق اللائحة العامة لحماية البيانات (GDPR) أو اللائحة البريطانية، تستند
المعالجة إلى المصلحة المشروعة في تشغيل معرض أعمال آمن والرد على الاستفسارات
المهنية، وإلى موافقتك عندما تختار استخدام ميزات اختيارية، وإلى الامتثال
للالتزامات القانونية عند الحاجة.

## 7. الاحتفاظ بالبيانات

أحتفظ بالمعلومات الشخصية فقط للمدة المعقولة اللازمة للغرض الذي قُدِّمت من أجله،
كالتعامل مع استفسار أو إدارة علاقة مهنية قائمة، ما لم يتطلب القانون مدة أطول.

لا يحتفظ الموقع بتفضيل السمة على خوادمه. وتحتفظ الخدمات ذات الصلة بسجلات
الاستضافة وبيانات التعليقات والبيانات التي تُرسَل عبر خدمات خارجية وفقًا
لسياساتها الخاصة.

## 8. النقل الدولي للبيانات

قد تعالج GitHub وGiscus وواتساب وMicrosoft ومقدمو خدماتها المعلومات في بلدان
غير بلدك. تتعامل هذه الخدمات مع عمليات النقل الدولي بموجب سياسات الخصوصية
والضمانات المطبقة لديها.

بحسب مكان إقامتك، قد يكون لك الحق في طلب الوصول إلى معلوماتك الشخصية أو
تصحيحها أو حذفها أو تقييد معالجتها أو الاعتراض عليها. وقد يكون لك أيضًا الحق
في سحب الموافقة عندما تستند المعالجة إليها.

لطلب متعلق بمعلومات أحتفظ بها، راسلني على
[moamen.khadra@outlook.com](mailto:moamen.khadra@outlook.com). أما الطلبات

إلى مزود الخدمة المعني. ويمكن لزوار المنطقة الاقتصادية الأوروبية/المملكة
المتحدة كذلك تقديم شكوى إلى سلطة حماية البيانات المحلية.
