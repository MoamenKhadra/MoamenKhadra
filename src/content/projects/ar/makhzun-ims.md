نظام "مخزون" لإدارة المستودعات والأصول، مبني لوزارة حكومية سعودية،
يغطي دورة حياة أصناف المخزون كاملة عبر الوحدات العسكرية
والإدارية — مستودعان في الواقع: واجهة Angular وخلفية .NET.

## قبل وبعد

**قبل** — كان المخزون يتحرك على الورق وجداول الإكسل: الأصناف تصل
ضد أوامر الشراء وتُسلَّم للوحدات، وتغيّرات الحيازة تُدوَّن يدويًا.
لا أحد يستطيع تتبّع رقم تسلسلي أو إثبات من يملك صنفًا أو إخراج
تقرير لمستودع واحد.

**بعد** — كل صنف يمر عبر مسار مُحكم (أوامر الوارد ← الصرف ← الحيازة
← التحويلات ← الإرجاع)، وكل رقم تسلسلي قابل للتتبع من أوله لآخره،
وكل مستودع لا يرى إلا مخزونه بينما تحتفظ الوزارة بمصدر واحد للحقيقة.

## أبرز المزايا

- **عزل متعدد حسب المستودع** — قاعدة بيانات مشتركة مع عزل على مستوى
  الصف عبر `WarehouseId`؛ ورأس `X-Warehouse-Id` لا يُوثق به أبدًا بل
  يتحقق منه الخادم ضد العضوية الفعّالة، فيُرفض الرأس المزوَّر بدل
  أن يكشف مخزون مستودع آخر.
- **سير أعمال الحيازة** — التحويلات والإرجاع يمران بحالات صريحة
  (قيد ← مقبول/مرفوض) بتواريخ هجرية وميلادية، وتسليم صلاحية أمين
  المستودع يعيد إسناد الأوامر النشطة مع نقطة استرجاع.
- **أمين واحد لكل مستودع** — مفروض في قاعدة البيانات بفهرس فريد
  مُفلتر، لا في كود التطبيق فقط.
- **تتبّع الأرقام التسلسلية** — ابحث عن أي رقم لتتبع الصنف من أمر
  الوارد حتى الصرف والحيازة والتحويل.
- **خلفية بمعمارية نظيفة** — .NET 8 مع CQRS عبر MediatR وخط
  FluentValidation وMapster و89 هجرة EF Core تُطبَّق تلقائيًا عند
  الإقلاع، مع متحكّمات رقيقة تُرجع غلاف `ApiResponse` متسقًا.
- **مصادقة بلا تخزين رموز** — JWT يصل كتعريف httpOnly مع تدوير رمز
  التحديث، فلا يُكتب أي رمز وصول في `localStorage`.
- **14 تقرير PDF** — تقارير QuestPDF للأرقام التسلسلية حسب الوحدة
  والصرف حسب الأمر وتحويلات ومرتجعات الحيازة والكميات المتبقية، كلها
  محصورة في المستودع المطلِب.
- **سجل ونسخ احتياطي** — وسيط سجل العمليات يوثّق التغييرات،
  والمديرون يمكنهم نسخ قاعدة البيانات واستعادتها من الواجهة.

## مَن يستخدمه

- **أمينو المستودعات** — يستلمون أوامر الوارد ويصرفون الأصناف
  ويسلّمون الحيازة بين الوحدات.
- **المستخدمون المتقدمون** — ينشئون التحويلات والإرجاع داخل
  المستودع المخصص لهم.
- **المديرون** — يديرون المستودعات والمستخدمين على مستوى عام
  ويراجعون الحيازة ويشغّلون التقارير لكل المستودعات.

## التقنيات

الواجهة Angular 22 بمكوّنات مستقلة وكشف تغييرات بلا Zone وإشارات
(signals)، مصمَّمة بـ Spartan UI فوق Tailwind CSS v4 وdaisyUI، مع
TanStack Table للجداول وApexCharts للوحة المعلومات وdayjs بدعم
التقويم الهجري. الخلفية .NET 8 بمعمارية نظيفة (Domain ← Application
← Infrastructure ← API) مع SQL Server وEF Core وASP.NET Core Identity
وSerilog وQuestPDF.

## النتائج

- حيازة كل صنف مثبتة — من يحمله ومتى ومن خلال أي تحويلات.
- العزل بين المستودعات مفروض في SQL وفي الوسيط، لا مجرد إخفاء في
  الواجهة.
- تقارير كانت تُطابَق يدويًا تخرج الآن كملفات PDF محصورة في
  المستودع الصحيح.
