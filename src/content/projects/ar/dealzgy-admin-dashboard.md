لوحة التحكم الداخلية لمنصة ديلزي (Dealzgy) لمقارنة الأسعار وتجميع
المنتجات — الواجهة الخلفية التي تُدار فيها عمليات الزحف وتُنقَّح
القوائم الخام إلى كتالوج موحّد.

## قبل وبعد

**قبل** — كانت البيانات تصل بلا انقطاع من آلاف المتاجر، لكن
الخط بلا رؤية: لا أحد يعرف أي المتاجر تتعثّر ولا سرعة العمال ولا
لماذا تُفشل مطابقتان لقائمة واحدة مع المنتج نفسه.

**بعد** — لوحة واحدة تعرض صحة الزحف لحظيًا وتمنح المشرفين أدوات
ربط منتجات المتاجر الخام بالكيانات الأساسية مع محتوى ثنائي اللغة
وعلامات وفئات وسمات.

## أبرز المزايا

- **مراقبة الزحف** — خرائط حرارية وشجرة وخاطوف وسلاسل زمنية
  لمحاولات الزحف، مع عروض سريعة وكاملة وعميقة وساخنة لكل متجر.
- **تشغيل الخط** — العمال (السعة، أوضاع يدوي/تلقائي، الإسناد لكل
  متجر)، وبروكسي، ومهام مجدولة، وقواعد أولوية في تنقّل واحد.
- **كتالوج بطبقتين** — منتجات المتاجر الخام (سعر الفئة الأولى،
  التقييم، المراجعات، عروض البائعين، سجل السعر) منفصلة عن المنتجات
  الأساسية المُنقَّحة، مع ربط صريح بينهما لتوحيد الكيانات.
- **إدارة محتوى ثنائي اللغة** — المنتجات الأساسية تحمل محتوى مترجمًا
  `en`/`ar` مع مبدلات `dir="rtl"` في صفحات المنتج، إلى جانب العلامات
  والفئات (شجرة) والسمات ومجموعات السمات والأنواع والكلمات
  المفتاحية.
- **مصادقة حسب الدور عبر Keycloak** — `keycloak-angular` مع حراسة
  تسجيل دخول إلزامية وتحديث تلقائي للرمز وتسجيل خروج عند الخمول
  وحارس أدوار يوجّه غير المصرّح لهم إلى صفحة ممنوع.
- **إعدادات أثناء التشغيل** — التطبيق يُقلاع بقراءة
  `configs/config.json` الذي يملؤه `docker-entrypoint.sh` عبر
  `envsubst` عند بدء الحاوية، فتُحقن روابط API وKeycloak لكل بيئة
  بدل تثبيتها في الحزمة.
- **صفحة منتج أساسية** — معرض صور ومحتوى نصي غني عبر Quill 2
  وقائمة منتجات المتاجر المرتبطة في شاشة واحدة.

## مَن يستخدمه

- **مشرفو البيانات** — يربطون قوائم المتاجر بالمنتجات الأساسية
  ويحافظون على المحتوى ثنائي اللغة.
- **مشغّلو المنصة** — يراقبون نسب نجاح الزحف والفشل ويعدّلون حدود
  الطلبات ويديرون العمال والوكلاء والمهام.
- **مسؤولو الفئات** — يحافظون على شجرة الفئات ومجموعات السمات
  والكلمات المفتاحية.

## التقنيات

Angular 19 بمكوّنات مستقلة وكشف تغييرات OnPush وإشارات، وPrimeNG 19
بغمامة مخصصة فوق Tailwind CSS v4، وApexCharts عبر `ng-apexcharts`
للرسوم البيانية للمراقبة، وQuill 2 للمحتوى النصي، وKeycloak
للهوية. يُنشر كصورة Docker متعددة المراحل تقدّمها nginx، مع GitHub
Actions يبني ويرفع إلى سجل حاويات Vultr على فروع `dev` و`staging`
و`main`.

## النتائج

- أعطال الزحف تظهر كرسوم بيانية بدل ثغرات صامتة في الكتالوج.
- قوائم المتاجر والمنتجات الأساسية مربوطة بوضوح، فيبقى طبقة المقارنة
  موثوقة.
- روابط البيئة تُحقن عند بدء الحاوية بدل إعادة البناء لكل بيئة.
