لعبة ذاكرة بطاقات بتيمز Pokémon بواجهة متجاوبة وتكامل مباشر مع واجهة
برمجية خارجية، بُنيت لتعميق استخدام بنية Angular والتدفق التفاعلي للبيانات.

## أبرز المزايا

- **جلب بيانات تفاعلي** — RxJS و`HttpClient` يسحبان بيانات البطاقات من
  PokéAPI ويتعاملان مع حالات التحميل والخطأ بوضوح.
- **نتائج محفوظة** — تبقى أفضل النتائج بعد إعادة تحميل الصفحة عبر
  `localStorage`.
- **منطق أداء عالٍ** — هياكل بيانات فعّالة تجعل الخلط والمقارنة فوريًا
  حتى على الهواتف المتوسطة.
- **لوحة متجاوبة** — شبكة Tailwind CSS تتكيّف من الهواتف إلى أجهزة
  المكتب دون تخطيط منفصل للهاتف.

## التقنيات المستخدمة

Angular وTypeScript لبنية المكوّنات، وTailwind CSS للتنسيق، وRxJS
للتدفقات، وPokéAPI كمصدر للبيانات.
