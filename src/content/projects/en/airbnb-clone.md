A full-stack clone of Airbnb, built as a team project during the ALX
Software Engineering Program — from console-based object storage up to
a deployed web app.

## Highlights

- **Flask + MySQL backend** — listings, users, and reservations are
  managed through REST endpoints backed by a relational schema with an
  ORM layer.
- **Dynamic front end** — property listings render with filtering and
  search so guests can narrow results by location and dates.
- **Production deployment** — configured behind NGINX with a
  master-slave MySQL architecture for redundancy.

## Versions

The project evolved through four stages: `v1` (console interpreter and
file storage), `v2` (MySQL setup), `v3` (Flask web framework), and
`v4` (full front end, APIs, and deployment).
